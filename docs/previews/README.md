# Visual fixtures

These images were rendered in Chromium using the actual application CSS and representative static markup derived from the Blade screens. They are layout previews, not screenshots of a running Laravel backend. Bootstrap vendor assets were not installed in the build environment. The values shown are example/seed-data fixtures. They do not demonstrate successful authentication, database integration, or Blade compilation.

The sidebar, topbar, and focus images show the three layout configurations. The sign-in and mobile images provide additional visual checks.
